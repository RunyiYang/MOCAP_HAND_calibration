GROUND-TRUTH BOUNDARY

现在能说什么，不能说什么

SUPPORTED CLAIMS

✓ 当前证据支持

  • 共同有效区间 1748 / 1805 / 1800 帧逐帧都有 120 Hz MOCAP bracket
  • BAG color message i ↔ MP4 frame i 已通过解码内容与 ±2 帧错位反证 gate
  • 旧回调时刻错位约 237–303 ms；逐行恢复到相机采集时刻
  • 视觉 zero-lag motion correlation 从 0.395–0.626 提升到 0.876–0.899
  • 残余峰值 +10 / +16 / +17 ms，均在一帧内且没有回写成拟合参数
  • delivered depth-camera pose 是严格 SE(3)，00 分块重复性和跨 Take 静态 RGB fixed-view gate 已通过
  • 三段 raw depth 共同区间 1747 / 1804 / 1799 帧均使用 depth 自身 timestamp，并提供逐帧 CSV
  • rear wrist proxy 只新增两个显示点；原始双手 42 joints、骨长、时间映射与 BVH 均保持不变

UNSUPPORTED CLAIMS

× 当前还不能宣称

  • glove 独立的 absolute wrist translation、orientation 或完整 6DoF 精度
  • Human.cma 每个节点都是实体 Marker 的直接测量
  • 橙色 rear wrist proxy 是后腕模块的实测中心、传感器 lever arm 或新增 GT joint
  • 剔除了所有遮挡、补点和低置信 MOCAP 帧
  • 相机外参已通过独立完整 21 点像素真值
  • 已查看的 Take 02/03 可继续充当全盲 final test

因此，当前已经得到可审计的“曝光时刻逐帧匹配”，足以审阅动作相位；要把它升级为最终 GT，还需共享硬件触发、原始 Marker 质量、官方外参和独立 2D held-out 标注。
