核心修正逐行公式：

\[
\ell_r=\texttt{thor\_realtime\_ns}_r-1000\cdot\texttt{color\_device\_timestamp\_us}_r
\]

\[
t^{C}_{r,acq}=\texttt{cmavatar\_windows\_estimated\_ns}_r-\ell_r
\]

RGB acquisition time 经 clock-map interpolation 得到 CMAvatar target time，再在相邻 120 Hz `FrameCounter` 之间用
(\alpha=(t-m_k)/(m_{k+1}-m_k)) 做位置线性插值。PTP cadence 采用
(m_k=\bar w+a(p_k-\bar p)) 锚定到 Windows timestamp；因 absolute PTP epoch contract 未交付，不能宣称硬件 PTP 绝对同步。

## 已知边界

- 100% coverage 只针对裁剪后的连续有效片段，不针对完整 source MP4。
- 全帧内容 gate 逐 index 比较 240×135 解码灰度+dHash，但不是原始编码 bit-exact，也不验证空间精度或硬件零时差。
- 同步是软件 clock mapping；没有 shared exposure/OptiTrack TTL。
- `PtpTimeStamp` 只提供高分辨率 cadence，absolute epoch 仍由 Windows timestamp affine anchor。
- 相机外参来自人工 CS-400 marker identity + 109 帧 raw-depth median；forward 3×3 block 不是严格正交。
- 可用的是固定 raw-depth camera SE(3)，不是逐帧 Femto Bolt trajectory；同 serial/内参本身不能证明相机绝对没动。
- Depth overlay 使用 depth 自己的设备时间戳；depth−RGB 约 1.31 ms 的实测差没有被抹掉或替换。
- Projected joint/wrist 的 nonzero depth coverage 只验证数据/投影覆盖，不是骨架到可见表面的误差或独立空间 accuracy。
- 没有独立逐帧 2D joint labels，无法报告 full-motion pixel reprojection error。
- `Human.cma` 没有 joint confidence、visibility、occlusion、gap-fill 或 residual。
- MOCAP skeleton 投影落在手部是 review evidence，不是 MOCAP 自身或 glove 的独立物理精度证明。
- 后侧 wrist proxy 是由 wrist→middle MCP 反向外推的显示点，不是实测 rear-module rigid body；全局 `+Z37 mm` 已被 depth 反证，不能启用为 GT。
- 输出是 30 FPS CFR review video；数值同步必须读取 CSV timestamps。
